# 🚀 EMO Learners

**EMO Learners** is a free, dedicated platform for Indian students designed to empower them to learn, build real-world projects, and access top-tier curated tech resources.

## 🌟 Mission
Our goal is to build a vibrant community where students can transition from beginners to confident developers by providing high-quality resources, internships, and a collaborative environment. 

## 🏗️ What's Inside?
- **Home (`index.html`)**: The main landing page showcasing the platform's vision and offerings.
- **Resources (`resources.html`)**: A curated library of tech resources, guides, and roadmaps to kickstart your learning journey.
- **Internships (`internships.html`)**: Opportunities for students to gain real-world experience and build out their portfolios.
- **Community (`join.html`)**: Portals to join the growing Discord/WhatsApp communities of passionate learners.
- **About (`about.html`)**: The story behind EMO Learners and our founding team.

## 🛠️ Technology Stack
This platform is built as a blazing-fast, static website using:
- **HTML5** (Semantic structure)
- **CSS3** (Custom variables, modern layouts, glowing aesthetics)
- **Vanilla JavaScript** (Custom cursor, interactive components)
- **Vercel** (`vercel.json`) for seamless and rapid deployment.

## 🚀 Running Locally
To run this website locally, you don't need any complex build steps:
1. Clone the repository.
2. Open `index.html` directly in your browser.
*(Alternatively, you can serve the directory using a simple local server like `npx serve` or the Live Server extension in VS Code).*
